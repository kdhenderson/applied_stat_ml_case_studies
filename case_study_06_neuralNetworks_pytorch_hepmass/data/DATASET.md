# HEPMASS Dataset

The data files for this case study are not included in the repository due to their large size.

You can download the HEPMASS dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/347/hepmass).

After downloading, place the relevant files (e.g., `all_train.csv.gz`, `all_test.csv.gz`) in this directory.

For more information, see the main project [README](../../README.md).
